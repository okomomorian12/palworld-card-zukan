# パルワールドカード図鑑

GitHub Pagesで公開できる、ログイン不要のカードコレクション管理Webアプリです。

## 仕様
- 公式カードリストからカード情報を同期
- カード名・カード番号・弾・色・カード種別・レアリティ検索
- 所持枚数管理
- 所持／未所持／交換／お気に入り
- 弾ごとのコンプリート率
- JSONバックアップ／復元
- スマホ対応・PWA対応
- カードをタップすると公式カードリストを表示
- 自分で撮影したカード写真の登録機能はありません
- カード画像をこのリポジトリへコピー・再配布しません

## GitHub Pages
1. GitHubでPublic Repositoryを作成
2. このフォルダの `index.html` `manifest.webmanifest` `sw.js` をアップロード
3. Settings → Pages → Deploy from a branch
4. Branch: `main` / Folder: `/ (root)` を選択
5. Save

## 注意
公式カード情報・画像・商標等の権利は各権利者に帰属します。カード画像は公式サイト上で確認する設計です。
公式サイト: https://palworld-official-cardgame.com/cardlist
